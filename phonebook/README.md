The making of this program was simultaneously extrordinarily hard while also being a very interesting subject.
I have included the .vscode folder for those that choose to run this on their personal systems (adjust paths according to your file architecture). It will explain how this is made without using a makefile.
The rest of this project(except for main.cpp as it is fairly wasy to understand after going through the rest of the files.) is heavily documented for it being my very first time making such a project, and therefore learning from it.
To anyone reading this, begin by going through the header files in /include in order of Contact.h->HashTable.h->Trie.h->BST.h->PhoneBook.h, after which you should go through /src in any order, so long as it ends in PhoneBook.cpp->main.cpp.
This project includes a sample AI generated contacts.csv file, with over 50,000 made up contacts.
Feel free to experiment. Thank you
